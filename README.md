# Laugh Track: The Crypto Trading Joke Contest

A make.fun bounty entry. `main.ts` writes a single one-line joke about crypto and trading life to `entry.txt`.

> I bought the dip, then the dip bought a shovel and kept digging.

Run with `MAKEFUN_OUTPUT_DIR` set to choose where `entry.txt` is written (defaults to `/output`).
